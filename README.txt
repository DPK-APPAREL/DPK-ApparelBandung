# DPK Jersey Website Prototype

File:
- index.html = struktur halaman
- style.css = tampilan/responsive
- script.js = interaksi menu, FAQ, dan form WhatsApp

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Untuk online, upload ketiga file ke folder public_html hosting.

Catatan:
- Nomor WhatsApp prototype: 0851-3726-7771.
- Harga pada prototype masih contoh dan perlu disesuaikan.
- Galeri menggunakan placeholder visual; ganti dengan foto jersey asli DPK.
- Untuk produksi website, sebaiknya tambahkan domain, favicon, analytics, SEO, foto produk asli, testimoni, dan kebijakan privasi.
